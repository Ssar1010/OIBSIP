# 📊 Data Science Projects

## Overview

This repository contains Data Science and Machine Learning projects developed using Python, Jupyter Notebook, Pandas, Scikit-learn, Matplotlib, and Seaborn.

The projects cover:
- Exploratory Data Analysis (EDA)
- Data visualization
- Machine learning classification and regression
- Model evaluation and interpretation

---

# Projects

## 🌸 Iris Flower Classification

**Objective:**  
Classify iris flower species (Setosa, Versicolor, Virginica) using machine learning models based on flower measurements.

**Techniques:**
- Data exploration and visualization
- Feature analysis
- Train/test split
- Classification model comparison

**Models:**
- Logistic Regression
- K-Nearest Neighbours
- Decision Tree / Random Forest

**Evaluation:**
- Accuracy
- Precision, Recall, F1-score
- Confusion Matrix
